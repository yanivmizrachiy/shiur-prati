## שכבת הבדיקה החדשה
### 1. סיווג `visualExpectation` לכל 50 המנועים
ב-`pedagogy-registry.js` (`E.VISUAL_EXPECTATION` + `E.getVisualExpectation`):
- **essential (30)** — ציור חובה כמעט בכל שאלה: כל הגאומטריה, מערכת צירים/ציר
  מספרים, כל תרשימי האי-ודאות, הסתברות, גרפים/פונקציות, קנה מידה.
- **recommended (10)** — ציור עוזר ומופיע בחלק משמעותי: חיבור/חיסור מכוונים,
  שורש, אחוז, יחס/פרופורציה, ממוצע/חציון/טווח.
- **optional (10)** — טקסטואלי מטבעו: ביטויים, הצבה, משוואות, מערכת משוואות,
  כפל/חילוק מכוונים, חזקות, כללי סימנים.

### 2. verifier חדש `verify:visual-coverage`
דוגם 168 הפקות לכל מנוע ואוכף:
- essential → **≥ 95%** מהדגימות עם `<svg>`/`<table>`.
- recommended → **≥ 30%**.
- optional → ללא דרישה.
אם מנוע essential אינו מצייר — הבדיקה נכשלת. הבדיקה משולבת ב-`verify:deep`
וכותבת `docs/reports/VISUAL_COVERAGE_MATRIX.json`.
