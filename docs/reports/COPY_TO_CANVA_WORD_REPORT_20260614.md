# דוח: העתקת שאלה שלמה (כולל ציור) ל-Canva / Word — 2026-06-14

## השאלה שנבדקה
"בכל פעם שמורה יוצר שאלה — האם הוא יכול ללחוץ כפתור אמיתי ולהעתיק את השאלה
*כולל הציור/הגרף והסעיפים* ל-Canva/Word, או להוריד את התמונה למחשב?"

## מה נמצא (בדיקה עמוקה, כנה)
לפני: כפתורי «העתק» העתיקו **טקסט בלבד** — הציור הוחלף ב-"[שרטוט]". רק «⤓ PNG»
(הורדה) כלל את הציור. כלומר **לא** היה כפתור אחד שמעתיק את השאלה *עם הציור*
ללוח כדי להדביק ב-Canva/Word.

## מה תוקן
נוסף `Teacher.copyImage(i)` + כפתור **«🖼 העתק כתמונה»** בסרגל הכלים של כל שאלה:
- מצלם את כל כרטיס השאלה (טקסט + שרטוט/גרף + סעיפים) ב-`html2canvas`
  (כפתורי המורה מוחרגים עם `data-html2canvas-ignore`).
- כותב **תמונת PNG ללוח** דרך `navigator.clipboard.write([new ClipboardItem({'image/png': blob})])`
  → המורה מדביק ישירות ב-Canva / Word / Docs.
- אם הדפדפן חוסם העתקת תמונה (אין מחווה/הרשאה) — **נפילה אוטומטית להורדת PNG**
  של אותה תמונה, כך שהמורה תמיד מקבל את השאלה השלמה עם הציור.

נשמרים גם «⤓ PNG» (הורדה), «⤓ HTML» (כולל SVG), ו«＋ לדף עבודה».

## הוכחה (QA בדפדפן אמיתי)
על שאלת G8-05 (זווית מרכזית, עם שרטוט גזרה):
- `html2canvas` הפיק תמונה **1050×1006**; **3.32% מהפיקסלים צבעוניים** — כלומר
  השרטוט (גזרה כחולה, תווית זווית אדומה) **באמת נכנס לתמונה** (טקסט הוא גווני אפור).
- `ClipboardItem` ו-`clipboard.write` נתמכים בדפדפן.
- קריאה ל-`Teacher.copyImage(0)` רצה ללא שגיאה; בהקשר אוטומטי (ללא מחווה) הדפדפן
  חסם והפעיל את הנפילה להורדת PNG — בלחיצת מורה אמיתית התמונה תועתק ללוח.
- 0 שגיאות קונסול.
