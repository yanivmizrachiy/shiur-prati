# דוח סנכרון מקור ושיפור מחולל — 2026-06-17

## מטרה

ליישר את המחולל, מסמכי המקור והדוחות כך שכולם יתארו את אותם נושאים, בלי סתירות בין הקוד לבין 10 קובצי המקור.

## מקור אמת עדכני

- `docs/SOURCE_BIBLE.md` — מיפוי מקור→מנוע→משפחות שאלה.
- `generator/engine/source-registry.js` — metadata מחייב לכל 50 מנועי השאלה.
- `generator/engine/pedagogy-registry.js` — מטרות למידה, טעויות נפוצות ומשפחות שאלה.
- `docs/reports/QUESTION_COVERAGE_CENSUS_LATEST.md` — מפקד כיסוי שאלות עדכני.
- `docs/reports/VISUAL_COVERAGE_MATRIX.json` — מטריצת כיסוי גרפי עדכנית.

## החלטות סנכרון

| מזהה | נושא מחייב | הערה |
|---|---|---|
| `A7-04-ENGINE` | ביטויים שקולים ופישוט | כולל פישוט, שקילות, שוויון לכל ערך, ושאלות מציאת טעות בביטויים. |
| `A7-05-ENGINE` | טבלת ערכים וגרף ברביע ראשון | כולל בניית טבלה, סימון נקודות, קריאת ערכים, וקישור ביטוי↔טבלה↔גרף. |

## תיקונים שבוצעו

- תוקן באג במצב רב-ברירה מרובה: `A7-04-ENGINE` כבר לא מפיק שאלת תשובה אחת במסלול `mcqMode=multi`.
- הוחלף המיפוי הישן שבו `A7-05` הוצג כ"מציאת טעות בביטויים".
- עודכנו אינדקס התבניות, מטריצות הכיסוי, דוחות source-fit, ודוח הכיסוי החזותי.
- `verify:source-fit` חוזק עם guard שמפיל את הבדיקה אם המיפוי הישן חוזר למסמכים הפעילים.
- דוח הכיסוי החזותי רוענן מה-JSON העדכני.

## אימותים

- `npm run verify:source-fit` — עבר, כולל guard נגד סתירות `A7-04/A7-05`.
- `npm run verify:deep` — עבר מלא לאחר התיקון.
- `git diff --check` — עבר נקי.
- בדיקת דפדפן חיה: `A7-04-ENGINE`, מצב `mcq`, מצב `multi`, שישה תרגילים, בכל אחד שתי תשובות נכונות, ללא `undefined` וללא `NaN`.

## שארית מכוונת

מסמכים היסטוריים מתוארכים נשארים בריפו, אך כאשר הם עלולים להטעות נוספה להם הערת מצב או עודכן הטקסט הרלוונטי. מקור האמת הפעיל הוא הרשימה למעלה, לא דוחות היסטוריים בודדים.
