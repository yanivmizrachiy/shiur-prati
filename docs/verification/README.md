# docs/verification

תיקייה זו מיועדת לתוצרי אימות ידניים או נוצרים אוטומטית שאינם חלק מקוד המוצר.

## נשמרים כאן
- תצוגות HTML שימושיות לבדיקת מורה/QA, למשל `teacher-generator-gallery.html`.
- תמונות או artifacts רק אם הם מייצגים בדיקה עדכנית ושימושית.

## לא נשמרים כאן כברירת מחדל
- `generator-live-latest.md` ו-`generator-live-latest.json` ישנים עם `Status: FAIL`, כי הם עלולים להטעות כאשר הכשל הוא בסקריפט הבדיקה ולא במוצר.
- דוחות live רגעיים צריכים להתחדש דרך workflow או להישמר כ-artifact זמני, לא כמקור אמת ידני.

## כלל
קוד המוצר נמצא ב-`generator/`. תיקייה זו אינה נדרשת להרצת האתר החי.
