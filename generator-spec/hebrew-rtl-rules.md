# Hebrew RTL Rules

## Main rule

All user-facing product content must be written in Hebrew only and displayed in right-to-left layout.

## Applies to

- Main interface
- Navigation
- Buttons
- Teacher controls
- Question text
- Worksheet text
- Hints
- Answers
- Error messages
- Empty states
- Exported images
- Printed worksheets

## Typography

The product must use clear, readable Hebrew typography suitable for teachers and middle-school students.

## Mathematical notation

Mathematical notation must remain accurate and readable inside Hebrew RTL text.

## Forbidden

- Awkward English labels in the product UI
- Mixed direction layout that breaks Hebrew reading order
- Cropped Hebrew text
- Misaligned mathematical symbols
- Fake placeholder Hebrew content

## Quality check

Every generated question must be checked visually in RTL before it is considered ready.
